# Trimmed aws-sdk-swift

This is not the official AWS SDK for Swift. It is upstream
[aws-sdk-swift 1.7.60](https://github.com/awslabs/aws-sdk-swift/tree/1.7.60) (`61b8c1968aeae4d42226e3b452ab864fd0b96523`)
with every service client removed except the ones Splitwise and amplify-swift 2.61.0 use.
Nothing else is changed.

It works around https://github.com/awslabs/aws-sdk-swift/issues/2218. Generated by
`scripts/aws-sdk-swift-fork/trim.sh` in the splitwise-iphone repo. Don't edit it by hand.

Services kept: AWSCloudWatchLogs AWSCognitoIdentity AWSCognitoIdentityProvider AWSComprehend AWSFirehose AWSKinesis AWSLocation AWSPinpoint AWSPolly AWSRekognition AWSS3 AWSTextract AWSTranscribeStreaming AWSTranslate
